# Governance — README

Este diretório contém o esqueleto de governança para o ACAS/ATLAS. Durante a fase de pesquisa, mantemos a governança no mesmo repositório para facilitar revisão.

Estrutura

- GOVERNANCE.md — documento principal de governança
- SECURITY.md — políticas e referências de segurança
- PUBLIC_KEYS/ — chave(s) públicas e instruções
- TRUST_ANCHORS/ — anchors (ex.: repositório assinado) e instruções
- CHANGE_PROPOSALS/ — onde as ACPs (ACAS Change Proposals) são armazenadas

Uso

- Public keys e fingerprints devem ser adicionadas em PUBLIC_KEYS/ e entregues como commits assinados.
- Propostas de mudança (ACP) devem seguir o template em docs/acas-foundation/ACAS-Change-Proposal-Template.md e ser colocadas em CHANGE_PROPOSALS/.
