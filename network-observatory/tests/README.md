# Tests

Espaço reservado para testes de unidade, contrato, integração e invariantes.

Prioridades iniciais:

- isolamento entre clientes;
- idempotência da sincronização;
- deduplicação de incidentes;
- classificação entre medido e inferido;
- funcionamento sem LLM;
- comportamento fora do horário operacional;
- rejeição de autenticação e autorização inválidas.
