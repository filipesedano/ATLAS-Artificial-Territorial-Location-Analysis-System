# Web

Interface do ATLAS acessada por técnicos, operadores e clientes autorizados.

Responsabilidades futuras:

- autenticação e seleção do ambiente do cliente;
- inventário e estados operacionais;
- globo/topologia interativa;
- incidentes, evidências e linha do tempo;
- acessibilidade e modo gráfico reduzido;
- comunicação com o Control Plane, nunca diretamente com equipamentos do cliente.

O navegador não deve executar monitoramento de rede.
