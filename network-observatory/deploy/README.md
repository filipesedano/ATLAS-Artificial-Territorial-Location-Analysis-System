# Deploy

Exemplos futuros de implantação do Control Plane e do Collector.

Regras:

- nenhum segredo real no repositório;
- variáveis documentadas em arquivos de exemplo;
- privilégios mínimos;
- conexões autenticadas e criptografadas;
- backups e restauração testáveis;
- ambientes de desenvolvimento, homologação e produção separados.
