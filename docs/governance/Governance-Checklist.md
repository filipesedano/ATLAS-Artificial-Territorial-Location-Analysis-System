# Governance Checklist

Checklist sugerido para PRs e entregas relacionadas à governança arquitetural.

Identificação
- [ ] Title claro e com ID se aplicável (ex.: ACAS-009).
- [ ] Arquivos colocados em `docs/governance/` ou `docs/architecture/` conforme apropriado.

Conteúdo mínimo
- [ ] Objetivo da entrega descrito.
- [ ] Escopo completo dos artefatos listado.
- [ ] Justificativa arquitetural apresentada.
- [ ] Alternativas consideradas documentadas.
- [ ] Impactos e riscos identificados.
- [ ] Próximos passos ou plano de implementação referenciado (em ADR/roadmap).

Procedural
- [ ] PR marcado como Draft quando for base de discussão/infra documental.
- [ ] Labels adicionados: governance, architecture, documentation, ci, research, ACAS-<NNN>.
- [ ] Nenhuma mudança funcional incluída neste PR inicial (se aplicável).

Rastreabilidade
- [ ] Issues/PRs/Componentes afetados referenciados.
- [ ] Diagrama(s) e artefatos de suporte incluídos ou referenciados.

Validação final
- [ ] Checklist interno preenchido e anexado ao PR.
- [ ] Responsável(s) pela proposta identificados.
