# ACAS Architecture Governance

Este diretório contém a base da Governança Arquitetural do ACAS (ATLAS - Artificial Territorial Location Analysis System).

Objetivo
- Estabelecer processos, padrões e artefatos para tomada de decisão arquitetural, documentação e rastreabilidade.

Escopo
- Guidelines para decisões arquiteturais (ADRs), padrões de documentação, guia de contribuição e checklist de governança.

Organização
- Decision-Lifecycle.md — ciclo de vida das decisões arquiteturais.
- Documentation-Standards.md — padrões e convenções de documentação.
- Contribution-Guide.md — como contribuir para a governança.
- Governance-Checklist.md — checklist de validação para PRs relacionados à governança.

Nota
- Os "próximos passos" específicos de cada decisão arquitetural devem constar no recurso de arquitetura correspondente (ex.: ACAS-009-Adaptive-Normality-Architecture.md) e no Roadmap do projeto.
