# Atlas-Sistema-Inteligente-de-Moradia-v3.0
ATLAS é uma plataforma de inteligência territorial que utiliza Inteligência Artificial para analisar bairros, cidades e regiões com base em infraestrutura, mobilidade, qualidade de vida, saúde, custos e preferências do usuário, gerando recomendações explicáveis para apoiar decisões de moradia.
